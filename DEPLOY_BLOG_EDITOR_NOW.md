## 🚀 Deploy Now

### Step 1: Build is Already Done
The `dist` folder is ready with the latest changes.

### Step 2: Upload to Hostinger
1. Open FileZilla
2. Connect to your Hostinger server
3. Navigate to `public_html`
4. Upload the entire `dist` folder contents
5. Overwrite existing files

### Step 3: Test
1. Go to: `https://www.skilltude.com/admin/login`
2. Login to admin
3. Click "Create New Article" or edit existing
4. You'll see TWO buttons in Content section:
   - **Rich Text** (default)
   - **Markdown**

### Step 4: Try Both Modes

#### Rich Text Mode
- Click formatting buttons to format text
- Use toolbar for headers, bold, italic, lists
- Click link icon to add links
- Click image icon to add images

#### Markdown Mode
- Write in markdown syntax
- See live preview on the right
- Toggle preview on/off with button
- Paste from external markdown editors

### Step 5: Publish
- Save as draft or publish
- View on blog to see formatted output
- Proper spacing and typography

## 🎯 Key Features

### Rich Text Editor
```
[B] [I] [H1] [H2] [H3] [•] [1.] [🔗] [🖼️] [↶] [↷]
```
Click buttons to format!

### Markdown Editor
```markdown
**bold** *italic* 
# Header 1
## Header 2
- List item
[link](url)
```
Live preview shows formatted output!

## 📝 Usage Tips

1. **For quick posts**: Use Rich Text mode
2. **For markdown fans**: Use Markdown mode
3. **Switch anytime**: Click mode buttons to switch
4. **Preview before publish**: Both modes show what you'll get
