## How to Use Rich Text Editor

### Method 1: Type Fresh Content (RECOMMENDED)
1. Click in the editor
2. Start typing
3. Press **Enter** to create new paragraphs (spacing is automatic!)
4. Select text and use toolbar buttons to format:
   - **B** = Bold
   - **I** = Italic
   - **H1, H2, H3** = Headers
   - **Bullet/Number** = Lists

### Method 2: Paste and Format
If you have plain text to paste:

1. Paste your text into the editor
2. It will appear as plain text (this is normal!)
3. Now format it:
   - **For paragraphs**: Place cursor at end of paragraph, press Enter twice
   - **For headers**: Select the line, click H1/H2/H3
   - **For bold**: Select text, click B
   - **For lists**: Select items, click list button

### Method 3: Convert Markdown to Rich Text
If you have markdown:

1. Ask ChatGPT: "Convert this markdown to plain text with clear paragraph breaks"
2. Paste the plain text
3. Format using toolbar buttons
4. OR just use the Markdown editor instead!

## Common Issues & Solutions

### Issue: "Paragraphs are too close together"
**Solution**: Make sure you're pressing Enter to create new paragraphs. Each Enter creates a `<p>` tag with spacing.

### Issue: "I pasted text and it has no formatting"
**Solution**: That's expected! Pasting gives plain text. Now format it:
- Select heading text → Click H1/H2/H3
- Select text to emphasize → Click B or I
- Highlight list items → Click list button

### Issue: "I want to paste formatted content"
**Solution**: Use the Markdown editor instead. It's designed for pasting pre-formatted content.

## Pro Tips

1. **Press Enter once** = New paragraph with spacing
2. **Press Shift+Enter** = Line break within same paragraph (no spacing)
3. **Use toolbar buttons** = Instant formatting
4. **Undo button** = Fix mistakes quickly
5. **Save often** = Don't lose your work

## When to Use Rich Text vs Markdown

### Use Rich Text When:
- ✅ Writing fresh content from scratch
- ✅ You prefer visual formatting
- ✅ You want to see formatting as you type
- ✅ You're comfortable with Word/Google Docs style editing

### Use Markdown When:
- ✅ Pasting from external markdown editors
- ✅ You already have markdown content
- ✅ You prefer keyboard shortcuts
- ✅ You want side-by-side preview

## Example Workflow

### Writing a Blog Post in Rich Text:

1. **Title**: Type your title, select it, click H1
2. **Intro**: Type intro paragraph, press Enter
3. **Section Header**: Type header, select it, click H2
4. **Content**: Type content, press Enter between paragraphs
5. **Bold key points**: Select text, click B
6. **Add lists**: Type items, select them, click list button
7. **Save**: Click "Publish" or "Save Draft"

## The Key Difference

**Rich Text Editor** = Like Microsoft Word
- Type and format as you go
- Visual, intuitive
- Great for writing fresh content

**Markdown Editor** = Like a code editor
- Write in syntax, see preview
- Great for pasting pre-formatted content
- Faster if you know markdown
